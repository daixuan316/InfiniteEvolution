# 02｜世界地图与白天探索

## 1. 地图模型

每章使用一张半开放区域地图，由横向主干道、上下层支路、室内空间和地下捷径组成。地图主体手工设计，确保路线可读和事件节奏；每日对宝箱、敌群、天气影响、临时封路和动态事件进行受控变化。

不使用完全随机拼接地图。随机性用于改变路线价值，不用于破坏已学习的空间认知。

## 2. 空间层级

### 区域地图

展示已发现地标、方舟位置、捷径、天气、危险等级和地点资源倾向。玩家可标记目标，但不从地图界面瞬移。

### 街区

负责移动、战斗、资源节点和路线选择。每个街区应拥有一个远景或结构地标，使玩家不看小地图也能大致判断位置。

### 室内地点

提供更高密度的搜刮、事件和环境叙事。室内规模控制在 30–120 秒可完成，避免白天时间大量消耗在重复走廊。

### 隐藏支路

通过雷达、幸存者情报、破墙工具、恢复电力或环境线索发现。隐藏内容以蓝图、独特装备、故事档案和永久捷径为主。

### 界面术语与切换边界

| 术语 | 定义 | 操作边界 |
|---|---|---|
| 区域情报地图 | 用于地点选择、风险评估和路线规划的选择／导航 UI | 点击节点只选中并展开固定详情栏；只有详情栏内黄色“确认出发”加载探索关卡，不提供瞬移 |
| 探索战场 | 玩家直接控制角色移动、战斗、搜刮和互动的世界空间 | 显示玩家、敌人、摇杆、技能/互动/翻滚控件和战场小地图 |
| 小地图 | 探索 HUD 中显示玩家、目标、路线与方舟方向的导航器 | 点击可查看完整地图；小地图与探索中完整地图均不提供传送 |

“区域地图”描述章节空间时仍指地理结构；描述选点界面时统一称“区域情报地图”。地图界面与战场效果图、独立素材及层级规则见[地图 UI 与探索辨识度素材库](17-map-ui-exploration-assets.md)。

## 3. 地点模板

| 地点 | 主要奖励 | 常见威胁 | 特殊互动 |
|---|---|---|---|
| 医院 | 医疗物资、抗污染、医生线索 | 感染区、狭窄伏击 | 恢复净化设备 |
| 超市 | 通用物资、食物、幸存者事件 | 数量型尸群 | 推车搬运、限时封门 |
| 警局 | 枪械、蓝图、电子元件 | 装甲敌人、锁区 | 查找密码和武器库 |
| 工厂 | 机械零件、方舟模块 | 机械危险、高噪音 | 启动生产线或吊机 |
| 实验区 | 变异组织、生化装备 | 高污染、精英怪 | 样本选择与风险研究 |
| 地铁 | 捷径、缓存、区域任务 | 黑暗、掘地者 | 供电、轨道切换 |
| 住宅区 | 幸存者、故事物品、通用资源 | 室内伏击 | 道德事件、救援 |

每个章节至少包含四种通用地点和一种章节独有地点。

## 4. 探索资源约束

### 时间

白昼基础 6–8 分钟。章节事件可上下浮动不超过 20%。天气、伤势或科技可以改变有效探索时间，但不得让玩家无法通过普通路线安全返回。

### 背包

- 使用格子＋物品堆叠，不使用精确重量模拟。
- 装备占一格；大型方舟模块占两格或需要搬运工具。
- 任务关键物品进入独立栏，不占普通空间。
- 背包满时拾取界面支持原地比较、拆解或丢弃。

### 伤势

伤势不是即时扣血，而是跨阶段的状态，例如移动速度降低、治疗上限下降或翻滚冷却增加。伤势数量设置上限，避免多重负面效果让角色失去操作能力。

### 污染

污染区、生化武器和异变箱提高污染。污染达到阈值后依次触发可预警效果：

1. 视觉与音频轻度干扰。
2. 治疗效率下降。
3. 异变能力增强，同时周期出现失控风险。

污染不会无提示瞬间杀死玩家。

## 5. 宝箱与搜刮

| 类型 | 开启成本 | 奖励倾向 |
|---|---|---|
| 普通物资箱 | 无 | 通用材料 |
| 加密军械箱 | 密码卡或短交互 | 武器和战术装备 |
| 污染生物箱 | 污染容量、可能伏击 | 变异组织和异变装备 |
| 重型保险柜 | 工具、时间、噪音 | 高品质装备和蓝图 |
| 空投箱 | 限时争夺、多波敌人 | 定向稀有奖励 |
| 隐藏缓存点 | 情报、雷达或环境解谜 | 独特物品和档案 |

搜刮交互遵循“普通箱快速、重要箱有决策”的原则。普通容器不使用重复长按进度条。

## 6. 动态区域状态

区域状态跨天保存，主要来源包括：

- 尸巢是否清除。
- 变电站、净化器、电梯和大门是否修复。
- 特殊感染者是否逃脱。
- 高噪音活动是否吸引敌群。
- 天气造成的积水、酸雾、火灾或坍塌。
- 幸存者任务对路线和地点的改变。

每项变化必须同时回答三个问题：地图上如何表现、影响什么玩法、何时恢复或永久保留。

## 7. 事件系统

### 即时事件

- 求救信号
- 游商
- 假求救伏击
- 建筑坍塌
- 空投争夺
- 精英迁徙

### 持续事件

- 修复设施
- 尸巢扩张
- 酸雨周期
- 幸存者失踪
- BOSS 活动痕迹

事件选择不使用不透明的善恶分。界面直接描述可预期代价，隐藏部分只用于惊喜，不能决定主线能否继续。

## 8. 返程压力

日落分为黄昏警报、黑夜降临、极夜追猎三个阶段：

- 黄昏警报显示最短已知路线。
- 黑夜降低视野并强化敌人，同时提高污染增长。
- 极夜生成不可被稳定清空的追猎压力，明确要求撤离。

紧急撤离是保底，不是常规最优方案。其代价是丢失部分未固定物资、增加伤势，并失去当日完整返程奖励。

## 9. 路线设计规则

- 每个主要地点至少有两条到达路径。
- 高收益死路必须提供可见的撤离方案或风险警告。
- 必经路线不使用需要随机掉落钥匙才能开启的门。
- 新机制先在低威胁空间展示，再与战斗组合。
- 重要地标从两个以上街区可见。
- 单次无决策的纯跑图不超过 20 秒。

## 10. 探索验收

- 玩家第二次进入同一章节时能利用已学路线提高效率。
- 每个白天至少出现一次“继续深入或返程”的真实取舍。
- 地点奖励倾向与实际掉落基本一致。
- 日落前从关键地点均存在理论可行的返程路线。
- 动态变化有明确视觉记录，不只写在结算文本中。
- 关键蓝图、剧情物品和 BOSS 削弱任务都有保底路径。
