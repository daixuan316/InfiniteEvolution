# 05｜成长、经济与制造

## 1. 成长层级

| 层级 | 时间尺度 | 主要内容 |
|---|---|---|
| 即时 | 单场战斗 | 掉落、治疗、临时状态 |
| 每日 | 一个昼夜 | 装备强化、模块维修、岗位分配 |
| 章节 | 7–10 天 | 科技分支、方舟阶段、BOSS 核心 |
| 全流程 | 五章 | 完整构筑、结局路线、远征解锁 |

全部成长跨章节保留。后续章节通过区域材料、环境规则、供电上限和新敌人机制建立压力。

## 2. 资源

| 资源 | 来源 | 用途 |
|---|---|---|
| 金币 | 丧尸、结算、交易 | 常规升级、维修、商店 |
| 废料 | 广泛搜刮 | 基础建造、强化、维修 |
| 机械零件 | 工厂、机械敌人 | 武器、炮塔、履带 |
| 电子元件 | 警局、实验区 | 雷达、电网、自动化 |
| 医疗物资 | 医院、救援 | 治疗、复苏、生化研究 |
| 变异组织 | 精英、污染区 | 角色、装备、方舟进化 |
| BOSS 核心 | 章节 BOSS | 关键科技、迁徙能力 |

区域材料用于高阶升级，但旧材料始终能合成、维修或交易。

## 3. 掉落职责

- 普通丧尸提供稳定金币和少量废料。
- 特殊感染者提供对应机制材料和装备概率。
- 精英稳定掉落变异组织与较高品质装备。
- 宝箱提供装备、蓝图和地点主题材料。
- 任务提供可预期的定向奖励。
- BOSS 提供唯一核心、传说装备和章节能力。

关键进度物品不进入无保底随机池。

## 4. 角色等级

经验来自战斗、探索、事件和夜间防守。升级提供小幅基础属性和一个天赋点；特定等级解锁技能槽、器官槽或系统功能。

角色等级不能成为唯一强度来源。装备、方舟和机制理解占据同等重要位置。

## 5. 天赋树

### 猎荒者

移动、撤离、搜刮、背包、隐藏点、污染抵抗。

### 枪械师

换弹、换枪、弱点、元素、移动射击、双武器联动。

### 守望者

维修、炮塔标记、方舟附近增益、应急供电、防线支援。

树内允许混点。浅层节点稳定易懂，深层节点改变玩法。洗点消耗常规资源并随章节提供有限免费次数，避免试错焦虑。

## 6. 方舟科技

| 分支 | 内容 |
|---|---|
| 工坊 | 制造、改装、高级配件、拆解回收 |
| 防御 | 炮塔、装甲、电网、维修无人机 |
| 探索 | 雷达、情报、背包、撤离设备 |
| 生化 | 变异组织、污染控制、活体模块 |
| 能源 | 发电、储能、过载、供电优化 |

关键节点消耗 BOSS 核心，普通节点消耗金币和材料。BOSS 核心数量应允许玩家完成一条主路线并触及另一条，而不能一次点满全部分支。

## 7. 制造

制造配方包括模板、材料、工坊等级、科技要求和产出。制造的目标是保证玩家能获得想要的武器类型，随机掉落负责提供更优组合和惊喜。

制造流程必须先验证材料、产出空间和解锁条件，再一次性扣除并发放，不能出现材料已扣但物品未生成。

## 8. 强化与等级同步

- 强化提高基础属性，不增加词条。
- 装备等级不能超过角色等级或章节软上限。
- 低等级高品质装备可同步到当前阶段。
- 同步成本低于重新打造同品质装备，但高于普通强化。
- 强化材料可通过拆解回收一部分。

## 9. 改装

- 每件装备只能指定一个普通词条槽反复改装。
- 可锁定结果池的类别，不能直接指定最高数值。
- 改装成本递增并设置软上限。
- 固定特性和进化特性不能用普通改装替换。
- 传说装备允许通过专属任务改变一次核心分支。

## 10. 拆解

拆解返还基础材料，并根据品质提供：

- 标签样本。
- 进化样本。
- 少量强化材料。
- 首次拆解图鉴记录。

已收藏、已装备、方案引用和传说以上装备默认不能被批量拆解。

## 11. 商店与交易

商店每日提供：

- 稳定基础材料。
- 少量地点主题材料。
- 一件可预览词条的装备。
- 一项情报或地图服务。

商店不出售 BOSS 核心和主线必需蓝图。出售价格低于购买价格，防止无成本套利；价格波动只影响可选资源。

## 12. 经济闭环

主要收入：探索、尸潮、任务、拆解、交易。

主要支出：维修、制造、强化、改装、治疗、人员、科技和紧急撤离。

平衡目标：

- 普通探索成功可以支付基础维修并完成一次小升级。
- 高风险探索成功可以提前完成一项关键升级。
- 单次失败不会使玩家连续多日陷入维修债务。
- 玩家不能通过无限刷低级行尸获得高阶核心资源。

## 13. 经济验收

- 每种资源至少拥有两个长期用途。
- 旧材料进入新章节后仍保持稳定消耗。
- 目标武器模板可通过明确路径制造或获得。
- 随机掉落不阻塞主线进度。
- 玩家在首章能体验至少一次制造、强化、改装、拆解和科技选择。
- 章节结束时合理玩家无法点满所有科技，但不会因选错一项而无法通关。
