# 04｜角色战斗与装备系统

## 1. 战斗目标

战斗以低瞄准负担、高走位和构筑决策为核心。自动射击负责连续输出，玩家负责站位、目标优先级、翻滚、换枪、主动技能、维修和互动。战斗不能退化成只移动躲避，也不能要求移动端玩家持续拖动瞄准。

## 2. 操作

| 输入 | 功能 | 规则 |
|---|---|---|
| 左摇杆 | 移动 | 允许边走边射 |
| 自动射击 | 攻击当前目标 | 有有效目标时触发 |
| 目标标记 | 提高指定目标优先级 | 点击特殊怪或长按目标区 |
| 翻滚 | 位移和短时减伤 | 消耗体力并有冷却 |
| 技能 1/2 | 主动能力 | 允许按住预览范围 |
| 换枪 | 切换两把主武器 | 支持后台换弹或散热词条 |
| 互动 | 开箱、维修、救援 | 根据上下文切换图标 |

默认锁定顺序：正在攻击玩家的敌人 → 特殊感染者 → 被标记目标 → 最近有效目标 → 普通残血敌人。锁定逻辑受射程、遮挡、武器类型和玩家设置影响。

## 3. 战斗状态

- 生命：归零后倒地。
- 护盾：先于生命承伤，可由装备与技能恢复。
- 体力：服务翻滚和少数重型动作，不限制普通移动。
- 伤势：跨昼夜的轻度负面状态。
- 污染：提供风险与异化能力联动。
- 控制抗性：防止连续硬控导致无法操作。

同一种强控制对玩家连续生效时获得短时递增抗性。

## 4. 武器类别

| 类型 | 节奏 | 优势 | 代价 |
|---|---|---|---|
| 突击步枪 | 中速持续 | 泛用、稳定 | 专项能力较弱 |
| 冲锋枪 | 高射速 | 移动输出、叠状态 | 射程短、散布高 |
| 霰弹枪 | 爆发间隔 | 击退、破甲 | 近距离、装填慢 |
| 狙击枪 | 慢速单发 | 穿透、弱点 | 对数量型敌人弱 |
| 轻机枪 | 长时间压制 | 尸潮输出 | 换弹慢、移动惩罚 |
| 榴弹武器 | 弧线范围 | 群体与装甲 | 最小安全距离 |
| 火焰武器 | 持续喷射 | 区域封锁、反再生 | 过热快、射程短 |
| 电弧武器 | 连锁脉冲 | 控制、潮湿加成 | 单体伤害低 |
| 生化武器 | 污染驱动 | 强机制和异化联动 | 提高污染风险 |

## 5. 无限弹药规则

普通枪械不消耗库存弹药，但仍保留：

- 弹匣与换弹时间。
- 射速和射击间隔。
- 后坐力、散布和移动精度。
- 过热、散热和停火窗口。
- 有效射程与伤害衰减。
- 穿透、击退和弹道速度。

无限弹药的目的只是移除重复购买射击资格，不移除换弹时机和武器节奏。

## 6. 伤害模型

最终伤害由基础伤害、技能倍率、同类增伤池、暴击或弱点倍率、防御修正和状态修正组成。

设计要求：

- 同类百分比先加后乘，防止多个独立乘区失控。
- 暴击与弱点可以共存，但组合上限受控。
- 防御提供递减减伤，不使用简单“攻击低于防御即无伤”。
- 元素状态以机制差异为主，不只是不同颜色伤害。
- 普通敌人的难度优先通过职能组合，而非血量膨胀。

## 7. 元素与异常

| 元素 | 异常 | 战术用途 |
|---|---|---|
| 火焰 | 燃烧 | 阻止再生、持续区域伤害 |
| 电击 | 感电 | 连锁、短暂停顿，潮湿环境强化 |
| 腐蚀 | 破甲 | 降低装甲并伤害机械模块 |
| 冻结 | 冷却 | 减速、积累后短时冻结 |
| 生化 | 感染 | 扩散、异化构筑联动 |

BOSS 对硬控制有抗性，但保留状态积累带来的次级收益。

## 8. 装备槽位

- 两个主武器槽。
- 头盔：感知、弱点、抗污染。
- 护甲：生命、防御、受击效果。
- 手套：射速、换弹、技能联动。
- 战靴：移速、翻滚、地形抗性。
- 战术装置：无人机、地雷、护盾、诱饵。
- 进化器官：强机制能力和污染副作用。

装备没有耐久。装备实例拥有稳定 ID、模板 ID、等级、品质、词条、强化、进化和锁定状态。

## 9. 品质与词条

品质依次为普通、精良、稀有、史诗、传说、异变。

装备由四层组成：

1. 基础模板：决定手感和基础属性。
2. 固定特性：体现类别身份。
3. 随机词条：从类型受限词条池生成。
4. 进化特性：通过使用行为解锁。

词条分为输出、操控、元素、生存和方舟联动。每个装备类型排除无意义词条，例如狙击枪不生成近距离霰射角度，战靴不生成弹匣容量。

## 10. 战斗记忆进化

史诗及以上装备记录有效行为：

- 近距离命中和击杀。
- 弱点命中。
- 连续换枪作战。
- 方舟附近防守。
- 元素异常触发。
- 高污染状态下使用。

满足条件后提供两条可预览进化路线。例如步枪可在突击型和猎手型之间选择。选择改变机制和外观标记，不只增加数值。装备可消耗稀有资源重置一次，之后再次重置成本显著提高。

## 11. 标签共鸣

共鸣以 2–3 件触发，允许混搭：

- 雷暴：感电跳跃更多目标。
- 守望：方舟附近强化并为炮塔标记。
- 机械：换枪或技能驱动无人机与炮塔。
- 异化：污染提高输出但降低治疗。
- 猎荒：搜刮、撤离和精英猎杀。
- 重装：承伤积累反击能量，翻滚冷却增加。

标签效果必须展示已装备数量、下一档效果和冲突代价。

## 12. 装备操作

- 拾取时显示与当前同槽装备的核心差异，不铺满所有二级属性。
- 仓库支持品质、类型、标签、元素、收藏和可进化筛选。
- 一键拆解只作用于玩家预设规则，收藏、传说和已进化装备默认保护。
- 方案切换若缺少装备，只保留空槽并提示，不自动拆卸其他正在使用的关键装备。

## 13. 战斗验收

- 玩家不手动瞄准也能稳定处理普通敌人。
- 特殊怪出现时，目标标记能在一次操作内改变火力优先级。
- 两把不同武器的射击、换弹和站位节奏可明显区分。
- 每种元素至少拥有一个环境或怪物机制联动。
- 高品质装备的价值主要来自特性和进化，而非单纯更高攻击。
- 同阶段合理构筑击杀普通敌人约 0.5–1.5 秒，特殊怪约 2–10 秒。
