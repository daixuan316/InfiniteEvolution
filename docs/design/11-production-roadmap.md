# 11｜制作路线、测试与验收

## 1. 制作原则

先证明核心循环，再证明完整首章，最后扩展内容。任何阶段未达到验收标准，不进入大规模美术和关卡生产。

## 2. 里程碑 A：核心原型

### 内容

- 一个白天街区。
- 一个方舟防守场景。
- 一把步枪、一把霰弹枪。
- 行尸、奔袭者、巨躯者。
- 金币、废料、机械零件。
- 机枪塔、装甲板、发电机、工坊。
- 白天返程、黄昏升级、夜间尸潮完整闭环。

### 验证问题

- 探索与防守是否互相产生动力。
- 自动射击是否仍有足够操作空间。
- 方舟维修和升级是否形成有意义选择。
- 单日时长是否适合移动端。

### 通过标准

- 无开发者说明时，测试者能完成一个昼夜。
- 至少 70% 测试者理解日落返程。
- 测试者能指出一次明确的路线或升级取舍。
- 原型在目标设备保持操作稳定。

## 3. 里程碑 B：首章纵向切片

### 内容

- 灰港废城七天。
- 五类探索地点与动态事件。
- 六类基础敌人、两类精英、屠夫母体。
- 六种武器模板和完整装备槽。
- 方舟两级外观、布局、电力、噪音和一次活体进化。
- 一名核心幸存者及个人任务。
- 完整 UI、音频、存档、失败重试和章节迁徙。

### 通过标准

- 七天流程无阻塞完成。
- 新手在第三天前能独立完成常规整备。
- 至少三种不同构筑可击败 BOSS。
- 失败原因统计不存在单一不透明机制。
- 目标平台达到帧率、内存和包体阶段目标。

## 4. 里程碑 C：系统完备

- 完成所有武器类别、装备进化、方舟主要模块和科技。
- 完成尸潮导演、适应性变异和幸存者岗位。
- 完成配置校验、存档迁移和调试面板。
- 使用灰盒或复用资产验证第二至五章全部规则。

系统完备阶段仍不要求所有最终美术完成。

## 5. 里程碑 D：内容生产

按章节顺序制作：

1. 腐雨工业区。
2. 沉没地铁城。
3. 群脑实验带。
4. 零号隔离区。

每章遵循：灰盒路线 → 机制测试 → 敌人和 BOSS → 任务 → 美术替换 → 音频 → 性能 → 平衡。

## 6. 里程碑 E：Alpha

- 全主线可完成。
- 三个结局可达。
- 所有系统功能完整。
- 允许使用少量非最终资产，但不能缺失关键信息。
- 完成首次全流程经济和平衡审计。

## 7. 里程碑 F：Beta

- 最终资产和本地化基本完成。
- 无主线阻塞和高频崩溃。
- 完成机型适配、后台恢复、存档迁移和弱网测试。
- 只接受修复、平衡和低风险体验调整，不再新增大型系统。

## 8. 测试矩阵

### 功能

昼夜切换、装备、背包、制造、方舟、任务、BOSS、结局和存档。

### 平衡

低、中、高构筑；不同方舟流派；失败恢复；资源净收益。

### 体验

新手理解、HUD 可读性、操作误触、菜单路径、教学节奏。

### 性能

最大尸潮、最大特效、长时间游玩、章节切换、后台恢复。

### 兼容

16:9 至 20:9、不同 DPI、低内存设备、音频中断、平台弹窗。

### 存档

正常退出、异常退出、写入失败、旧版本迁移、快照损坏和重试。

## 9. 数据观察

测试构建重点记录：

- 每日探索路线和返程时间。
- 倒地与方舟失守原因。
- 资源收入、支出和库存。
- 武器、标签、天赋和模块使用率。
- 每晚尸潮预算与实际伤害来源。
- 界面停留时长和放弃点。
- 教学步骤失败和重复次数。

数据只用于定位问题，不能替代观察玩家为何做出选择。

## 10. 内容完成定义

### 一个武器完成

配置、模型或精灵、动画、音效、特效、词条池、两条进化、图标、文本、掉落、制造、测试全部完成。

### 一个怪物完成

职能、AI、动画、音效、预警、弱点、掉落、波次成本、图鉴和性能测试全部完成。

### 一个地点完成

路线、地标、资源、敌人、事件、动态状态、返程测试、美术、音频和性能全部完成。

### 一个章节完成

全部昼夜可连续完成，主线和 BOSS 无阻塞，经济闭环成立，存档可恢复，目标设备性能达标。

## 11. 风险与止损

| 风险 | 早期信号 | 止损措施 |
|---|---|---|
| 探索和防守割裂 | 玩家只期待其中一半 | 强化双向状态，删除孤立奖励 |
| 系统过多 | 第三天仍依赖提示 | 推迟解锁，合并界面和资源 |
| 自动射击被动 | 玩家只绕圈 | 增加目标、换枪、维修和站位责任 |
| 方舟布局复杂 | 整备长期超过三分钟 | 减少槽位和相邻规则 |
| 内容规模失控 | 首章未完成就制作后章 | 冻结后章资产，只做灰盒验证 |
| 性能不足 | 原型尸潮已掉帧 | 限制透明、AI频率和对象数量 |
| 随机掉落挫败 | 主线构筑长期缺件 | 增加制造、保底和定向任务 |

## 12. 首发验收

- 五章主线和三个结局均可完成。
- 没有已知存档破坏和主线阻塞。
- 所有适应性变异有预警和反制。
- 至少三种角色—装备—方舟构筑可通关。
- 关键 HUD 在支持比例和安全区下可读。
- 标准与省电模式均达到对应帧率目标。
- 新玩家能在首章内理解全部核心系统。
- 失败不会造成无法恢复的永久资源负循环。

## 13. 后续实施计划拆分顺序

1. 核心状态与配置基础。
2. 角色移动、自动射击和伤害。
3. 敌人、掉落和对象池。
4. 白天地图、搜刮和返程。
5. 方舟模块、供电和夜间波次。
6. 背包、装备、制造和成长。
7. 存档与失败重试。
8. 首章任务、BOSS、UI、音频和表现。

每一步都应形成可运行、可验证的纵向功能，不以创建空目录或占位类视为完成。
