# 00｜总览与设计支柱

## 1. 产品定义

《无限进化：末日方舟》是一款横屏 2D 章节制轻生存动作游戏。玩家白天离开移动方舟探索废墟，搜集物资、装备、蓝图和情报；日落前返回方舟进行制造、建设与人员调度；夜晚亲自参战并利用方舟防线抵御尸潮。章节末击败区域 BOSS 后，方舟携带全部成长迁往下一地区。

目标平台是抖音小游戏。单个普通昼夜控制在 10–15 分钟，黄昏与每日结算均可安全退出，既能形成完整小局体验，也能支撑连续游玩。

## 2. 玩家幻想

玩家不是被动躲在避难所中的幸存者，而是“末日方舟的驾驶者、猎荒者和守卫者”：

- 白天敢于离开安全区，用风险换取未来。
- 黄昏以有限资源决定方舟下一步如何成长。
- 夜晚亲自守住自己建造的防线。
- 从敌人身上夺取进化能力，让机械堡垒逐渐成为独一无二的末日生命体。

## 3. 四项设计支柱

### 3.1 风险必须可判断

探索中的时间、距离、负重、伤势和污染都应有清晰反馈。玩家失败可以源于判断失误，但不能源于看不见的规则。高风险地点必须在进入前展示至少一种警告，并对应更高价值或更定向的奖励。

### 3.2 探索与防守必须互相影响

白天清巢、修电站、调查 BOSS、营救工程师会改变夜晚；夜晚放跑特殊怪、制造高噪音、方舟受损会改变次日。任何只存在于单一阶段、又不产生长期选择的系统都应谨慎加入。

### 3.3 成长优先改变玩法

高阶装备、天赋和模块进化应改变目标优先级、射击节奏、布局方式或风险策略。纯百分比数值只能作为底层支撑，不能成为主要奖励。

### 3.4 压力来自取舍，不来自琐事

不做实时饥饿口渴、普通弹药消耗和装备耐久。保留真正影响路线与构筑的压力：白昼倒计时、背包、伤势、污染、电力、噪音、维修和士气。

## 4. 核心卖点

1. **昼夜双循环**：探索与塔防式守城在同一长期状态中连续发生。
2. **移动方舟**：庇护所可见、可损坏、可布局、可迁徙并持续改变外观。
3. **三重进化**：角色、装备和方舟吸收变异能力，同时承担副作用。
4. **战斗记忆装备**：高品质装备根据实际使用行为分化路线。
5. **适应性尸潮**：敌人针对长期战术变异，但给出提前情报和克制方案。
6. **动态区域**：地图道路、尸巢、天气、设施和敌群会跨天变化。

## 5. 目标用户

- 喜欢短时高密度循环，但又希望存在长期成长的移动端玩家。
- 喜欢自动攻击降低操作负担，同时仍希望通过走位与构筑体现技巧的玩家。
- 喜欢基地建设、装备掉落、塔防和末日题材交叉体验的玩家。

本作不以硬核射击准度、复杂饥饿模拟或完全自由建造为核心，不应以这些用户作为首要目标。

## 6. 体验节奏

| 时间尺度 | 玩家问题 | 主要回报 |
|---|---|---|
| 5–15 秒 | 先杀谁、站哪里、是否翻滚 | 战斗安全与即时爽感 |
| 1–3 分钟 | 进哪条支路、开哪个箱、何时撤离 | 材料、装备、事件 |
| 10–15 分钟 | 今天的探索是否值得、今晚如何守 | 日结算与方舟成长 |
| 1–2 小时 | 这一章发展什么构筑、如何削弱 BOSS | 章节核心与迁徙 |
| 完整流程 | 选择净化、共生还是支配 | 结局、远征与收藏 |

## 7. 范围边界

### 首发范围内

- 五章主线、约 41 个昼夜。
- 角色战斗、完整装备、方舟建设、怪物尸潮、幸存者和多结局。
- 远征、高危区、BOSS 再战和章节重访。
- 本地版本化存档及必要的平台接入预留。

### 首发范围外

- 多人联机和玩家交易。
- 完全自由的沙盒建造。
- 开放世界无缝地图。
- 实时饥饿、口渴、体温与弹药制造。
- 以抽卡作为装备和幸存者主要来源。
- 未经独立评审的广告和付费数值。

## 8. 成功标准

- 新玩家三分钟内理解“白天探索、夜晚守家”。
- 首章结束前至少出现三次清晰且有后果的路线或升级取舍。
- 玩家能用一句话描述自己的角色和方舟流派。
- 每章的新环境规则同时影响探索与防守。
- 失败后玩家能判断是路线、构筑、布局还是机制执行出了问题。
- 内容扩展主要通过数据和资产完成，不要求反复重写核心系统。
