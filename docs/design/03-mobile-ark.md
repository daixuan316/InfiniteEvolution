# 03｜移动方舟与庇护所建设

## 1. 系统定位

方舟同时承担主界面、长期成长、制造中心、幸存者居所和夜间防守目标。它必须在外观和战斗中展示玩家的建设结果，不能退化成只在菜单里增加百分比的科技树。

## 2. 空间结构

### 外层防线

装甲板、路障、电网、尖刺、诱饵和近防装置。主要功能是拖延、改变敌人路径和保护内部设施。

### 武器平台

机枪塔、霰弹塔、火焰塔、电磁塔、导弹架和无人机平台。主要功能是持续输出、控制和针对特殊怪。

### 内部设施

发电机、储能器、工坊、医疗室、仓库、雷达、研究台、宿舍和净化器。主要功能是长期成长和提供夜间主动能力。

## 3. 模块数据

每个模块拥有：

- 稳定 ID、类型与等级。
- 安装层级、占用槽位和朝向。
- 最大耐久、当前耐久和装甲类型。
- 基础耗电、过载耗电和噪音。
- 工作效率、攻击或功能参数。
- 相邻加成标签。
- 可选机械升级路线。
- 可选活体进化路线及副作用。
- 受损、停机、寄生和过载状态。

内容配置与运行时实例分离。升级不能更换稳定 ID，只更新实例等级和选择。

## 4. 布局

- 使用固定槽位而非像素级自由摆放。
- 正面、顶部、底部和内部槽位拥有不同可安装类型。
- 模块移动只在黄昏阶段免费完成；夜间只能切换预设应急线路，不能重新搭建整车。
- 炮塔界面显示射界、盲区和被遮挡范围。
- 供电界面显示线路、总容量和优先级。
- 支持保存三套布局方案；切换方案不自动制造缺失模块。

## 5. 耐久与维修

模块耐久分为：

- 70% 以上：完整工作。
- 30%–70%：显示受损，效率小幅下降。
- 1%–30%：严重受损，效率明显下降并可能触发故障。
- 0%：停机，不永久销毁。

普通维修消耗金币和废料；复杂生化模块需要对应材料。维修统一由方舟远程系统和自动维修无人机执行，玩家负责选择目标、队列、能源额度和优先级；不要求角色靠近模块，也不展示角色手动维修。夜间自动维修安全但耗电且效率低于黄昏整备阶段。

维修成本设每日上限保护：一次普通失败不能让玩家连续两天只能偿还维修债务。

## 6. 电力

### 供电状态

- 关闭：无功能、无耗电、几乎无噪音。
- 基础负载：维持最低功能。
- 标准负载：正常性能。
- 过载：短时强化，积累热量和故障风险。

### 优先级

玩家可把模块设为核心、重要、普通三档。供电不足时从普通档开始断电，同档按预设顺序处理。

### 应急机制

- 应急电池：短时间恢复一个线路。
- 手动转供：玩家在夜间操作配电箱，把能源转到指定区域。
- 发电机过载：提高总供电，但增加噪音、热量和损坏风险。

## 7. 噪音

噪音来源包括发电、制造、雷达、炮塔、广播和维修。噪音分为隐蔽、可察觉、高危、诱敌四档：

| 档位 | 效果 |
|---|---|
| 隐蔽 | 尸潮预算略低，稀有掉落不加成 |
| 可察觉 | 标准强度 |
| 高危 | 增加特殊感染者和结算倍率 |
| 诱敌 | 主动召来额外高潮波，显著提高变异材料 |

噪音必须在确认夜战前预测结果区间，不能让玩家在不知情时突然遭遇不可承受尸潮。

## 8. 相邻加成

相邻加成只使用少量清晰规则：

- 发电机靠近储能器：提高过载持续时间。
- 工坊靠近仓库：降低制造时间和材料损耗。
- 雷达靠近无人机平台：提高标记和巡逻范围。
- 医疗室靠近净化器：降低治疗产生的污染。
- 同类重武器相邻：提高火力，但扩大被范围攻击同时命中的风险。

每个模块最多显示两条主要相邻关系，避免布局变成不可读的连线谜题。

## 9. 活体进化

变异核心可植入指定模块。每次进化包含：

1. 明确的玩法能力。
2. 一个可量化副作用。
3. 外观变化。
4. 对应的夜间或探索联动。

| 模块 | 能力 | 副作用 |
|---|---|---|
| 机枪塔·追猎腺体 | 优先锁定残血与特殊怪 | 耗电、噪音上升 |
| 装甲·再生组织 | 喘息期恢复耐久 | 受到火焰伤害增加 |
| 雷达·感知器官 | 揭示隐藏缓存和伏击 | 方舟基础污染上升 |
| 发电机·电囊 | 电击击杀触发短时过载 | 故障概率提高 |
| 医疗室·共生舱 | 治疗并积累器官适应 | 士气事件概率上升 |

进化可通过稀有资源拆除，但拆除会损失核心的一部分价值，确保选择有重量又非永久锁死。

## 10. 方舟成长阶段

| 阶段 | 外观与结构 | 新玩法 |
|---|---|---|
| 改装运输车 | 单层车体、少量外挂 | 基础机枪与工坊 |
| 装甲履带堡垒 | 双层装甲、稳定底盘 | 完整供电和布局 |
| 移动工业平台 | 吊臂、重型平台 | 自动维修和重火力 |
| 生化机械方舟 | 活体组织与机械融合 | 模块进化和污染管理 |
| 末日移动城塞 | 多区段城塞 | 终局构筑和区域压制 |

升级后旧模块继续可用，不因方舟阶段变化被强制淘汰。

## 11. 构筑范型

- 炮塔海：高供电、高噪音、角色负责标记和应急供电，维修由无人机处理。
- 高压电网：控制与连锁，依赖潮湿环境和储能。
- 生化再生：低维修压力、高污染风险。
- 低噪潜行：尸潮较弱，稀有战利品倍率较低。
- 诱敌收割：主动提高威胁，用强力范围构筑换取材料。
- 重装堡垒：牺牲输出，用角色承担清除特殊怪的责任。

任何范型都不能同时拥有最高生存、最高输出和最高收益。

## 12. 夜间交互

玩家可在夜间：

- 调度自动维修无人机并调整维修队列。
- 手动启动过载。
- 切换供电优先级。
- 使用一次性应急电池。
- 启动远程净化脉冲清除寄生体。
- 操作重型炮台或释放方舟主动技能。

交互按钮只在有效范围和有效状态下出现。紧急操作使用短按，不使用容易误触的长按。

夜间维修交互不受角色站位限制；角色只在方舟顶部或内部处理战斗与主动设施，不能离开庇护所在外部手动维修。

## 13. 验收标准

- 玩家从方舟外观能判断当前阶段和主要构筑。
- 供电不足时，界面能明确展示即将停机的模块。
- 每次进化都同时改变能力、代价和外观。
- 夜间至少存在一个必须由角色处理、炮塔无法独立解决的威胁。
- 常规布局调整在 90 秒内完成。
- 一次失败不会永久摧毁稀有模块。
