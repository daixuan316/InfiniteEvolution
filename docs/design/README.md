## 已确认且不得随意漂移的决策

1. 横屏正交俯视 2D，角色与怪物可见头顶和肩部；Cocos Creator 3.8.8 + Oops Framework。
2. 章节战役制，每章 7–10 个昼夜。
3. 白天半开放区域探索，夜晚强制回到移动方舟防守。
4. 角色采用移动＋自动瞄准射击，玩家手动负责翻滚、技能、换枪和互动。
5. 子弹无限，通过弹匣、换弹、过热、射程和散布制造武器差异。
6. 使用轻生存压力：时间、背包、伤势、污染和方舟损坏；不做实时饥饿口渴。
7. 装备、资源、角色成长和方舟升级跨章节全部继承。
8. 方舟采用模块布局、电力、噪音和活体进化四个核心机制。
9. 尸潮可适应玩家战术，但必须提前预警并提供明确反制。
10. 先验证核心闭环，再制作首章纵向切片，禁止同时铺开五章生产。

## 变更规则

- 新需求先判断属于哪份专题文档，再修改对应规则。
- 影响两个以上系统的变更必须同时更新总览和所有关联文档。
- 改动“已确认决策”必须记录原因、影响范围和迁移方案。
- 实现代码、配置表和美术资产都应引用稳定 ID，不引用文档中的自然语言名称作为唯一标识。
- 文档禁止保留未定义占位项；不能确定的内容应明确排除出当前版本。
