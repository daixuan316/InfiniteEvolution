# 01｜核心循环与局内结构

## 1. 总流程

章节抵达 → 查看区域与尸潮情报 → 配置武器、技能、工具和方舟方案 → 白天探索 → 日落返程 → 黄昏治疗、制造、建设、供电、派员 → 夜间尸潮防守 → 结算损坏、掉落、区域变化与适应趋势 → 下一天 → 章节 BOSS 夜 → 方舟迁徙。

## 2. 单日结构

| 阶段 | 推荐时长 | 能否暂停 | 核心决策 |
|---|---:|---|---|
| 战前配置 | 1–2 分钟 | 是 | 带什么、去哪里、准备应对什么 |
| 白天探索 | 6–8 分钟 | 是 | 深入还是返程、带走什么 |
| 黄昏整备 | 1–3 分钟 | 是 | 资源投向装备还是方舟 |
| 夜间防守 | 3–5 分钟 | 是 | 火力、维修、供电和站位 |
| 每日结算 | 30–60 秒 | 是 | 接受后果并规划次日 |

BOSS 夜可延长至 6–8 分钟，但必须在阶段切换处提供短暂停顿。

## 3. 战前配置

玩家在方舟总览中完成：

1. 查看天气、地区事件、已知敌人和尸潮变异趋势。
2. 选择两把主武器、护具、战术装置和进化器官。
3. 选择至多两个主动技能。
4. 查看背包可用空间和探索工具。
5. 标记一个优先地点；标记只提供路线建议，不锁定行动。

系统允许保存三套角色方案和三套方舟方案。首次进入当天时推荐上次成功方案，但不自动替换玩家装备。

## 4. 白天探索

白天倒计时只在玩家进入探索区域后开始。进入室内、开背包和查看地图不会完全暂停时间，但时间流速降至 20%，避免利用菜单永久冻结风险；打开系统暂停界面则完全暂停。

白天必须持续提供三种选择：

- **路线选择**：安全近路、资源支路、危险深区。
- **容量选择**：保留高价值装备，还是带走更多建设材料。
- **时间选择**：继续完成事件，还是确保安全返程。

地图中的首次发现、捷径、修复设施和已救援幸存者跨天保留。

## 5. 黄昏整备

黄昏阶段不计时，防止玩家在复杂菜单中被迫快速决策。推荐顺序：

1. 处理伤势和污染。
2. 存放、拆解和标记装备。
3. 修复方舟。
4. 制造或强化本夜需要的装备。
5. 安装、移动和供电模块。
6. 分配幸存者岗位。
7. 确认开战。

若玩家跳过整备，系统沿用上一套有效供电和防守方案；损坏模块不会被自动花费稀有材料修复。

## 6. 夜间防守

标准夜晚由六段组成：

1. **预警**：展示主要方向、环境与异常信号。
2. **试探波**：用低密度敌人展示本夜机制。
3. **主攻波**：多职能敌人组合。
4. **喘息段**：暂停刷怪 15–25 秒，允许维修和供电调整。
5. **高潮波**：精英、特殊事件或小型首领。
6. **清剿**：停止增加威胁，处理残敌并结算。

角色在夜间承担四类职责：击杀特殊目标、保护防线薄弱点、维修关键模块、触发主动设施。炮塔不能完全代替角色，角色也不能无视方舟独自清场。

## 7. 章节节奏

### 七天章节模板

| 天数 | 功能 |
|---:|---|
| 1 | 认识区域规则，低压探索与基础尸潮 |
| 2 | 引入第一种特殊敌人和关键地点 |
| 3 | 开放支路与第一次设施修复 |
| 4 | 精英夜袭，检验基础构筑 |
| 5 | BOSS 情报与削弱任务 |
| 6 | 高收益准备日，允许补足关键资源 |
| 7 | BOSS 前置探索与最终夜 |

八至十天章节在中段增加规则组合、幸存者任务和第二次精英夜袭，不重复拉长纯刷取。

## 8. 失败与恢复

### 白天倒地

- 触发紧急救援并返回方舟。
- 损失部分未固定物资。
- 获得伤势，影响下一次行动。
- 蓝图、BOSS 核心和剧情物品不丢失。

### 夜间角色倒地

- 进入濒死倒计时。
- 可消耗医疗物资或由医生岗位复苏。
- 无法复苏时角色退出本夜，方舟仍继续承受攻击。

### 方舟核心被摧毁

- 从当日黄昏整备阶段重试。
- 保留已获得的敌人情报。
- 当夜消耗的临时资源回滚到黄昏快照。
- 不删除永久装备、角色等级和章节前进度。

## 9. 保存节点

- 章节抵达后。
- 白天出发前。
- 白天首次获得关键物品时做轻量增量保存。
- 返回方舟后。
- 黄昏确认开战前建立重试快照。
- 夜间结算后。
- 章节迁徙完成后。

禁止在伤害结算、掉落生成或模块移动到一半时写完整存档。

## 10. 节奏验收

- 普通日完整流程不超过 15 分钟的目标值。
- 白天最后两分钟至少产生一次明确撤离压力。
- 黄昏界面完成一次常规整备不超过 90 秒。
- 夜间每 60–90 秒出现一次节奏变化。
- 连续两个夜晚不能使用完全相同的波次结构和特殊敌人组合。
- 失败重试返回黄昏的加载与操作路径应短于 20 秒。
