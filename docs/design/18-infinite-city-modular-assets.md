# 18｜无限城市模块化地图资源

## 1. 用途

本批资源为白天无限探索提供高频普通街区，解决固定医院地图重复平铺、关键建筑过密、住宅不足的问题。

程序使用世界种子和区块坐标在下列资源中确定性选择：

- `residential-district-a`：低层公寓、联排住宅、院落和停车区。
- `residential-district-b`：更密集的公寓、联排住宅、小型活动场地和绿化院落。
- `neighborhood-commercial-a`：住宅为主体，混合便利店、无文字药店、修车库、加油设施和停车区。
- `hospital-district`：保留为低频医院关键地标，不参与普通住宅随机池。

## 2. 规格

- 单图尺寸：`1344×768` PNG，对应 `14×8` 个 96 世界单位逻辑格。
- 视角：严格俯视，无天空和地平线。
- 四个方向均在边缘中心保留道路连接。
- Cocos 导入使用 nearest 过滤、关闭 mipmap、clamp-to-edge。
- 图片不包含文字、角色、怪物、UI 或烘焙交互提示。

## 3. 风格

资源以现有医院城区为参考，通过 OpenAI 内置图像生成工具制作：

- 蓝灰混凝土建筑与深色沥青。
- 青色窗灯和设备作为科技强调。
- 橙黄色道路标线、雨棚和工业管线。
- 绿色植被、裂缝、积水和废弃车辆表现末世荒废。
- 普通区块不出现医院、警局、工厂或实验室等大型关键地标。

## 4. 运行时约束

本批图全部提供四向道路，因此生成器可以安全地在任何相邻区块间保持基础道路连续。逻辑碰撞和寻路仍由 `InfiniteChunkGenerator` 的道路格决定；图片只负责表现，不能成为第二套碰撞来源。

后续扩展弯道、T 字路和死路资源时，必须在资源清单中声明连接方向，并为相邻连接增加自动化接缝测试。
