## 共同执行规则

- 每个任务先写失败测试，再写最小实现。
- 纯规则层不得导入 cc，保证 Vitest 可直接运行。
- Cocos 组件只负责输入、节点生命周期和表现绑定。
- 静态配置、运行时实例、持久状态和表现状态必须分离。
- 每个计划完成后执行 yarn test 和相应的 Creator 编辑器验收。
- 只提交当前任务涉及的文件，不混入其他未跟踪项目文件。
