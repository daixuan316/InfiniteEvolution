# 地图宝箱、资源与交互物素材设计

> 日期：2026-11-03  
> 状态：依据已确认 UI 与世界素材方向执行  
> 视觉参考：`docs/design/assets/ui-main-gameplay-topdown-v1.png`

## 目标

补齐地图界面和俯视战场中缺失的宝箱、资源点、设施、机关与事件素材。每个玩法对象同时拥有一个地图/UI 标记和一个世界空间俯视物件，并共享稳定 ID，方便配置表、地图节点、掉落逻辑与 SpriteFrame 引用保持一致。

## 生产方案

采用“UI 标记＋世界物件”双层资产，而不是只制作宝箱图标：

- UI 标记用于区域地图、小地图、任务列表和互动提示，统一使用深蓝圆底、科技青描边与高对比白/语义色图形。
- 世界物件用于白天探索和方舟周边场景，采用正交高位俯视透明素材，保留小型接地阴影，不带 UI 框和交互光圈。
- 选中、锁定、已完成、危险、任务关联和可交互高亮由程序使用描边、角标、颜色和粒子表达，不为每个状态重复生成整张素材。

## 技术规格

- UI 标记：4×4 透明母版，每个切片 128×128 RGBA；使用与现有 UI 图标一致的圆形深蓝底托与青色边框。
- 世界物件：4×4 透明母版，每个切片 256×256 RGBA；正交高位俯视，统一光照、比例和接地阴影。
- UI 标记与世界物件使用相同 ID，分别位于 `ui-markers/` 和 `world-props/`。
- 文本、数量、品质角标、任务箭头、交互范围、碰撞体、开启动画和状态高亮全部由程序或后续动画资源负责。

## 色彩与轮廓规则

- 普通容器和机械设施：钢灰、冷白、科技青。
- 奖励与可操作部件：琥珀色。
- 医疗：白＋红；能量：青蓝；生物污染与变异：洋红；高危险与锁定：红；燃料与酸性危险：橙黄或黄绿。
- 世界物件在 96 px 显示尺寸下必须能通过轮廓分辨，UI 标记在 64 px 下必须保持含义清楚。

## 验收标准

- 两组各 16 个对象，共 32 个稳定 ID；每个 ID 同时拥有 UI 标记与世界物件，共 64 张成品。
- 所有成品透明、无文字、无数字、无水印、无相邻单元串图。
- UI 标记与现有 96 枚图标属于同一视觉家族；世界物件与灰港地图、人物和怪物使用相同像素密度与俯视角度。
- 文件数量、命名、尺寸、Alpha 与唯一性通过自动检查；生成来源和派生处理写入机器清单。
