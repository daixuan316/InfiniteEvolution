# Hall 主界面 C3 重装工业细节优化设计

日期：2026-11-08  
目标引擎：Cocos Creator 3.8.8  
设计分辨率：1334×750 横屏

## 目标

将当前 Hall 主界面优化为已确认的 C3「重装工业舱」方案。在保留现有车库背景、方舟主体、七个入口和导航逻辑的前提下，提升资源栏、方舟状态、尸潮预警和底部导航的组件质感、信息辨识度与视觉统一性。

本次只修改 Hall 主界面的视觉构成和必要的纯布局辅助逻辑，不改变 UIID、导航栈、演示数据结构、战斗入口行为及其他功能页。

## 已确认的视觉方向

- 延续像素末日工业风，使用深海军蓝、钢灰边框和青色能量线。
- 橙色只用于能源、关键数值和“出发探索”主行动。
- 洋红与红色只用于次夜尸潮和危险信息。
- 保留厚重金属框，但统一边框等级并减少无意义碎装饰。
- 中央方舟维持主视觉地位，不让状态面板或装饰遮挡主体。
- 使用现有真实图标；不以字符或临时图形代替正式图标。

## 页面构图

### 顶部状态栏

- 左侧显示章节、地点、天数和阶段。
- 右侧的废料、合金、能源由三张独立方框合并为一个金属资源轨道。
- 资源轨道内部使用图标、资源名、数值三层信息；各资源通过细分隔线区分。
- 资源图标使用独立深色芯片底座，数值比资源名更醒目。

### 左侧方舟状态

- 标题使用带青色侧边能量线的内嵌标题条，并保留方舟建设图标。
- 核心耐久与能源负载分别使用状态图标、名称、数值和分段能量条。
- 分段条替代当前普通连续色条，耐久使用青色，能源使用橙色。
- 可用模块槽位使用独立底部模块卡，显示 `5 / 7` 和七个槽位灯；五个点亮、两个熄灭。

### 中央方舟展示

- 保持当前车库背景与方舟插画，方舟等比缩放并居中。
- 标题位于方舟上方；整备提示位于方舟下方。
- 不新增大面积遮罩或完整中央面板，避免削弱场景表现。

### 右侧尸潮预警

- 标题条使用洋红能量线和污染图标，与普通状态区明确区分。
- 威胁等级改为切角警报牌，包含警戒提示、中等威胁和敌人类型。
- 倒计时整合为底部警戒模块，显示图标、标签和高亮数字。
- 倒计时模块底部加入黄黑警戒条，但不烘焙动态时间文本。

### 底部功能导航

- 六个功能入口继续显示大图标与短文字。
- 按钮统一使用切角金属底板、顶部青色能量线和图标芯片。
- “出发探索”比普通入口更宽，使用橙色能量线、橙褐底板和方向箭头，保持唯一主行动地位。
- 七个按钮的节点名、点击区域和导航绑定保持不变。

## 组件和资源边界

- `HallViewComp` 负责 Hall 的页面构成、数据展示和交互绑定。
- `HallLayout` 负责可独立测试的尺寸、分段状态和响应式布局计算。
- `UIBuilder` 继续负责面板、九宫格、图标、标签和纹理异步加载；只在 C3 组件确有通用价值时增加小型构建能力。
- `UITheme` 可以补充 C3 使用的钢灰、危险底色和能量线色，但不得破坏其他页面现有配色。
- 现有图标来自 `assets/bundle/gui/ui-icons/`；Hall 专属新底板素材如有必要，放入 `assets/bundle/gui/hall/texture/`。
- 动态文字、数字、进度和倒计时继续由 Cocos 节点渲染，不烘焙进 PNG。

## 交互与数据流

- Hall 创建时同步生成可交互节点，随后异步挂载纹理。
- 异步纹理完成后只更新 Sprite，不重建按钮、不重复绑定事件。
- 六个功能入口继续调用 `uiNavigation.push(route.id)`。
- “出发探索”继续调用 `uiNavigation.replace(UIID.BattleHUD)`，成功后派发 `GameEvent.EnterBattle`。
- 图标或纹理加载失败时保留程序绘制底板和可点击区域，不产生未处理异常。

## 适配与可读性

- 以 1334×750 为设计基准，并验证 1600×900、1800×900、1950×900。
- 关键内容保持在安全边距内；侧栏宽度、中央区域和按钮宽度由可用空间计算。
- 方舟插画保持原始宽高比，禁止拉伸。
- 文字、图标和动态数值之间保持最小间距，资源数值和倒计时不得被裁切。
- 开发版统计面板不属于 Hall UI；视觉验收截图中应关闭或隐藏统计信息。

## 测试与验收

- 为资源轨道、分段状态、模块槽位和底部导航补充纯布局或集成断言。
- 现有七个入口的节点名和绑定测试继续通过。
- `npm run test:ui` 全部通过。
- `npx tsc --noEmit` 不新增 TypeScript 错误。
- Cocos Creator 预览中无 Hall 资源加载红错。
- 1334×750 验收截图应满足：
  - 资源轨道不再像三张普通表格卡；
  - 方舟状态具有图标芯片、分段条和槽位灯；
  - 尸潮预警具有切角警报牌和整合倒计时；
  - 底部按钮统一，出发探索明显高于其他入口；
  - 中央方舟仍是页面第一视觉焦点。

## 非目标

- 不重做车库背景和方舟主体插画。
- 不修改资源、方舟和尸潮的业务数据来源。
- 不改造其他功能页、战斗 HUD 或全局导航框架。
- 不引入新的运行时依赖。
