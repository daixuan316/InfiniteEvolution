# 世界、人物与怪物视觉素材设计

> 日期：2026-11-03  
> 状态：基于已确认 UI 视觉基准执行  
> 参考：`docs/design/assets/ui-main-gameplay-topdown-v1.png`

## 目标

补齐现有 UI 效果图之外的世界地图、战斗场景、怪物本体、人物本体与 UI 展示头像，使地图情报、图鉴、成员管理、白天探索和夜间方舟防守拥有同一套可复用视觉来源。

## 统一视觉框架

- 正交高位俯视 2D 精细像素风；人物和怪物必须看到头顶与肩部，不采用侧视、等距菱形或 3A 写实。
- 环境以低饱和灰蓝、锈褐和脏绿为底；玩家与友军使用青白/稳定蓝；可交互物使用暖黄；感染和精英使用洋红；腐蚀使用酸性黄绿。
- 场景保持低对比可战斗区域，高对比只用于角色、怪物、危险区、目标物和可交互物。
- 人类使用方形、楔形和机械装备；怪物使用破碎、不对称、前倾轮廓，并让攻击器官直接表达职能。
- 所有文字、数值、血条和交互按钮由程序绘制，不烘焙进地图、角色或怪物素材。

## 资产范围

### 地图与场景

1. 灰港废城区域地图底图：港口、医院、警局、工厂、地铁、住宅区、污染区与方舟停靠位。
2. 白天医院街区战场：道路、医院屋顶、救护车、围栏、物资箱和可辨识路线。
3. 夜间方舟屋顶防守战场：玩家只在屋顶战斗平台或内部活动，尸潮位于方舟外围。
4. 六地点缩略图母版：医院、超市、警局、工厂、实验区、地铁。

### 怪物

1. 九种常规/特殊怪俯视本体：行尸、奔袭者、巨躯者、喷吐者、尖啸者、攀爬者、掘地者、寄生体、自爆体。
2. 五章 BOSS 与尸巢俯视本体：屠夫母体、酸雨巨囊、地铁吞噬者、群脑信标、原初进化体、感染尸巢。
3. 八种核心怪物图鉴头像：行尸、奔袭者、巨躯者、喷吐者、尖啸者、精英感染者、BOSS、尸巢。

### 人物

1. 六职业幸存者俯视本体：工程师、医生、侦察员、枪械师、生物学家、守卫。
2. 六职业幸存者 UI 半身头像，身份、服装和配色与俯视本体对应。
3. 主角四个战斗姿态参考：持枪待机、射击、翻滚、互动；只作为动画制作参考，不宣称为可直接播放的最终动画帧。

## 技术规格

- 地图与战场目标画布：1334×750，PNG RGB/RGBA；AI 输出后进行确定性中心裁切与尺寸规范化。
- 角色与怪物母版：透明 PNG；固定网格；切片后统一为 256×256 RGBA，中心锚点与透明边距一致。
- 地点缩略图：切片后统一为 512×288；允许后续 UI 使用裁切遮罩。
- 头像：切片后统一为 256×256 RGBA；保留头肩轮廓，不带姓名、职业字样或 UI 框。
- 像素图使用最近邻规范化；正式接入 Cocos Creator 时关闭线性过滤并在 64/96/128 px 显示尺寸复查。

## 验收标准

- 地图中不出现天空、地平线或等距投影；路线、地标与危险区在缩略尺寸仍可辨识。
- 怪物能在约一秒内通过轮廓区分职能；特殊器官不与身体轮廓合并。
- 人物职业能通过头部、肩部、装备和主色区分；头像与俯视本体保持同一身份。
- 夜间画面中玩家不在庇护所外战斗；维修仅由系统或无人机表达。
- 切片文件数量、命名、尺寸和 Alpha 通道通过自动检查；生成来源和处理过程写入清单。

## 生产顺序

1. 先生成区域地图、常规怪物本体、幸存者本体三张代表性母版，作为跨类别视觉校准。
2. 生成其余地图场景、BOSS、头像与主角姿态。
3. 确定性裁切、规范化、生成预览与机器清单。
4. 在项目文档中登记，完成基础 QA；正式运行时接入留给 Cocos Creator 实现阶段。
