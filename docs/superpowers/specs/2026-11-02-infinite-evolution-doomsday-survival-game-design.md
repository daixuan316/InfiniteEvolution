# 《无限进化：末日方舟》完整游戏策划案

> 文档版本：1.0  
> 日期：2026-11-02  
> 项目：InfiniteEvolutionDoomsdaySurvival  
> 引擎：Cocos Creator 3.8.8 + Oops Framework  
> 目标平台：抖音小游戏，横屏 1334×750  
> 文档状态：核心设计已确认，可进入实现计划拆分

## 1. 游戏概述

### 1.1 暂定名称

《无限进化：末日方舟》

### 1.2 类型与定位

横屏 2D、章节制、轻生存、自动瞄准射击、半开放地图探索、移动堡垒建设与尸潮防守。

玩家操控一名幸存者，白天从移动方舟出发，在半开放的末日废墟中规划路线、搜刮物资、寻找装备并处理事件；日落前返回方舟，利用当天获得的材料制造装备、调整供电、升级防线，随后抵御夜间尸潮。每章末击败区域 BOSS，驾驶持续进化的移动方舟前往下一区域。

装备、资源、角色成长和方舟升级全部跨章节继承。新章节通过新的资源层级、环境规则、敌人组合和供电压力提供挑战，不依靠清空玩家资产重新开始。

### 1.3 核心卖点

1. **昼夜双循环**：白天风险探索，夜晚角色与堡垒协同防守。
2. **可见、可损坏、可布局的移动方舟**：庇护所不是静态菜单，而是战斗主体。
3. **机械与生物融合进化**：角色、装备和方舟都能吸收变异能力，并承担副作用。
4. **动态末日区域**：夜间战果、噪音、尸巢和天气会改变次日地图。
5. **装备战斗记忆**：高品质装备根据玩家的实际使用方式形成不同进化路线。
6. **可预警的适应性尸潮**：敌人会针对玩家长期依赖的战术变异，但始终给出反制窗口。

### 1.4 目标体验

- 每个白天都产生“再深入一处，还是现在返程”的风险判断。
- 每个黄昏都产生“有限资源优先升级什么”的建设判断。
- 每个夜晚都要求玩家在射击、维修、补位和处理特殊感染者之间切换。
- 每个章节都引入一种新的环境规则，并以 BOSS 战检验玩家的探索和建设成果。
- 玩家能明显看到角色装备和方舟外观随流程持续成长。

### 1.5 明确不做

- 不设置普通弹药消耗，子弹无限。
- 不设置装备耐久，避免获得好装备后不敢使用。
- 不设置实时饥饿、口渴和体温条。
- 不采用六件套式强制套装构筑。
- 不让所有成长依赖纯随机掉落或无限洗词条。
- 不在本策划中定义广告、内购和付费数值；商业化另行评审，不能破坏核心循环。

## 2. 核心玩法循环

### 2.1 总循环

```text
查看区域情报与尸潮趋势
        ↓
配置装备、技能和探索工具
        ↓
白天探索：搜刮、事件、清巢、解锁捷径
        ↓
权衡时间、负重、伤势与污染，返回方舟
        ↓
黄昏整备：治疗、制造、建设、供电、人员分配
        ↓
夜晚防守：角色战斗、炮塔输出、维修与应急调度
        ↓
结算伤亡、损坏、资源与敌人适应趋势
        ↓
进入下一天；章节末击败 BOSS 后迁徙
```

### 2.2 白天：风险探索

- 从医院、商场、警局、工厂、实验区等地点中选择路线。
- 地点越远、污染越高、开启条件越复杂，奖励越好。
- 主要约束是白昼时间、背包容量、伤势和污染值。
- 玩家可清除尸巢、修复设施、营救幸存者、解锁捷径，使地图产生持久变化。
- 日落后不会立即失败，而是逐级进入高压撤离状态。

### 2.3 黄昏：有限资源决策

- 修复方舟受损模块。
- 制造、强化和改装装备。
- 安装或升级装甲、炮塔和内部设施。
- 分配幸存者岗位。
- 根据雷达情报调整武器、供电和防线位置。
- 电力不足时不能让所有设施同时满负荷运作。

### 2.4 夜晚：协同防守

- 炮塔负责稳定火力，角色负责移动补位和处理关键目标。
- 玩家可射击、换枪、释放技能、维修模块、启动应急设施。
- 特殊感染者会针对方舟的不同结构展开攻击。
- 普通丧尸掉落金币和少量废料，精英与特殊怪掉落变异材料。
- 防守越完整，次日获得的士气和探索增益越高；方舟受损会消耗后续资源维修。

### 2.5 章节循环

- 每章 7–10 个昼夜。
- 前半段教授区域规则，中段安排精英夜袭，后半段提供削弱 BOSS 的探索任务。
- 最终夜由强化尸潮和区域 BOSS 构成。
- 通关后方舟驶入下一区域，全部成长保留。

## 3. 时间、失败与存档规则

### 3.1 单日建议时长

| 阶段 | 目标时长 | 说明 |
|---|---:|---|
| 战前配置 | 1–2 分钟 | 可快速使用上次方案 |
| 白天探索 | 6–8 分钟 | 章节和事件可轻微调整 |
| 黄昏整备 | 1–3 分钟 | 可暂停，不计入白昼时间 |
| 夜间防守 | 3–5 分钟 | BOSS 夜延长至 6–8 分钟 |
| 结算 | 30–60 秒 | 展示关键变化，不堆叠弹窗 |

单个普通昼夜约 10–15 分钟。黄昏和每日结算时自动保存，允许玩家分段游玩。

### 3.2 角色倒地

- 白天倒地：触发紧急救援，带回方舟，损失部分未固定物资并增加伤势。
- 夜晚倒地：进入短暂濒死状态，可消耗医疗资源复苏；无资源时本夜由防线继续承担压力。
- 角色倒地不直接删除永久装备或角色等级。

### 3.3 方舟失守

- 方舟核心耐久归零即判定当夜失败。
- 玩家从当日黄昏整备阶段重新开始。
- 首次失败保留已获取情报，但消耗过的临时道具回滚，避免复制资源。
- 连续失败时提供敌人弱点提示和一次可选的防守配置建议，不直接降低永久难度。

### 3.4 强制返程

日落后分为三个阶段：

1. **黄昏警报**：显示最短返程路线。
2. **黑夜降临**：视野下降，普通敌人强化，污染增长加速。
3. **极夜追猎**：不可正面清空的追猎群出现，迫使玩家撤离。

紧急撤离会随机损失部分未固定物资。首次获得的蓝图、BOSS核心和剧情物品不会丢失。

## 4. 移动方舟系统

### 4.1 方舟定位

方舟是一辆可持续扩建的履带式移动堡垒。它既是主界面和制造中心，也是夜间防守的核心场景。方舟升级必须在外观、功能和战斗能力上同步体现。

### 4.2 三层结构

#### 外层防线

- 装甲板
- 路障
- 电网
- 诱饵装置
- 近防武器

#### 武器平台

- 机枪塔
- 霰弹塔
- 火焰塔
- 电磁塔
- 导弹架
- 无人机平台

#### 内部设施

- 发电机
- 储能装置
- 工坊
- 医疗室
- 仓库
- 雷达
- 研究台
- 宿舍与士气设施

每个模块拥有等级、耐久、耗电量、占用空间、工作状态和相邻加成。

### 4.3 布局规则

- 模块安装在明确槽位中，不采用完全自由摆放，保证移动端易操作和战斗可读性。
- 外层模块保护内层模块；部分敌人可绕过外层或直接攻击电缆。
- 炮塔射界、相邻设施和供电线路影响效率。
- 玩家可保存三套防守布局，在黄昏阶段一键切换后微调。

### 4.4 电力系统

电力决定模块是否工作及其负载等级：

- 基础负载：设施维持最低功能。
- 标准负载：正常工作。
- 过载：短时间强化，积累热量或故障风险。
- 断电：设施停机，但不继续制造噪音。

电力不足时，玩家需要在火力、照明、维修、医疗和制造之间取舍。应急电池可短时恢复关键模块，但不能代替长期能源建设。

### 4.5 噪音系统

高等级工坊、雷达、重型武器和过载发电会制造噪音。噪音会影响：

- 当晚尸潮威胁预算。
- 特殊感染者出现概率。
- 白天附近街区的敌人聚集。
- 高风险诱敌奖励倍率。

玩家可以关闭部分设施进行低噪防守，也可以主动开启广播诱饵，召来更危险的尸潮以换取更多金币和变异组织。

### 4.6 活体进化方舟

BOSS和特殊感染者掉落“变异核心”。核心可植入方舟模块，使机械设施获得生物特性：

| 模块 | 进化示例 | 代价示例 |
|---|---|---|
| 机枪塔 | 追猎腺体：优先锁定残血和特殊怪 | 耗电与噪音上升 |
| 装甲 | 再生组织：脱战后缓慢修复 | 怕火，维修材料改变 |
| 雷达 | 感知器官：发现隐藏宝箱和伏击 | 持续增加轻度污染 |
| 发电机 | 电囊：击杀电属性敌人后短暂过载 | 过载故障概率提高 |
| 医疗室 | 共生培养舱：加速治疗和器官适应 | 士气事件概率上升 |

每个模块只能选择一条主要进化方向。进化提供机制变化，并伴随耗电、噪音、污染或结构弱点，不能成为无代价的纯数值升级。

### 4.7 方舟成长阶段

1. **改装运输车**：基础机枪位和工坊。
2. **装甲履带堡垒**：双层防线和完整供电系统。
3. **移动工业平台**：自动维修和重型火炮。
4. **生化机械方舟**：模块进化与区域压制能力。
5. **末日移动城塞**：形成完整流派和终局外观。

可形成炮塔海、高压电网、生化再生、低噪潜行、高风险诱敌等不同方舟构筑。

## 5. 白天地图与探索

### 5.1 地图结构

每章是一张半开放区域地图，采用“横向主干道＋上下层支路＋室内场景”：

- 主干道移动快、敌人密集、资源较少。
- 屋顶、地下通道和建筑内部提供宝箱、蓝图与事件。
- 地图设置清晰地标、方舟方向指示和已发现捷径，避免横版场景迷路。
- 主体结构手工设计，宝箱、事件、敌群和部分道路每日变化。

### 5.2 地点与资源倾向

| 地点 | 主要资源 | 主要风险 |
|---|---|---|
| 医院 | 药品、医疗模块、抗污染材料 | 感染区、狭窄走廊 |
| 超市 | 通用物资、食物、幸存者事件 | 数量型尸群、争夺事件 |
| 警局 | 枪械、战术蓝图、电子元件 | 装甲感染者、锁区 |
| 工厂 | 金属、机械零件、方舟模块 | 机械危险、噪音累积 |
| 实验区 | 变异材料、生化装备、剧情信息 | 高污染、精英怪 |
| 地铁与下水道 | 捷径、稀有缓存、区域任务 | 黑暗、掘地型敌人 |

### 5.3 探索流程

1. 在方舟查看天气、尸潮预报和地点情报。
2. 选择装备、主动技能与探索工具。
3. 进入地图，自由决定路线。
4. 搜刮、解锁捷径、处理事件或清除尸巢。
5. 根据时间、负重、伤势和污染决定继续深入或返回。
6. 带回物资，进入黄昏整备。

### 5.4 宝箱类型

- 普通物资箱：直接开启。
- 加密军械箱：需要密码卡或短交互解锁。
- 污染生物箱：消耗污染容量开启，可能触发伏击。
- 重型保险柜：需要工具，开启过程制造噪音。
- 空投箱：限时出现，吸引多批敌人。
- 隐藏缓存点：通过地图线索、幸存者情报或雷达进化发现。

宝箱的关键不是颜色，而是开启成本、风险和资源倾向。

### 5.5 动态区域状态

- 放跑特殊感染者，次日对应区域可能出现巢穴。
- 大量使用高噪音武器，会使附近街区聚集敌人。
- 摧毁尸巢，可降低数日内的夜袭压力。
- 暴雨造成积水，开启导电战术和地下路线。
- 酸雾封锁部分道路，同时提高变异材料产量。
- 修复变电站、净化器和电梯会永久改变章节地图。

地图状态必须同时影响白天探索和夜间防守，避免两个玩法割裂。

## 6. 角色战斗

### 6.1 操作方案

- 左摇杆：移动。
- 自动射击：武器自动锁定有效射程内目标。
- 翻滚：短暂无敌或高减伤，受冷却限制。
- 主动技能：一至两个快捷按钮。
- 换枪：在两把主武器之间切换。
- 互动：开箱、救援、维修和启动设备。
- 目标标记：点击特殊目标，临时提高其锁定优先级。

默认锁定优先级：威胁玩家的敌人 → 特殊感染者 → 最近敌人 → 普通残血敌人。

### 6.2 武器类别

| 类型 | 核心特征 | 主要用途 |
|---|---|---|
| 突击步枪 | 稳定、通用 | 中距离持续输出 |
| 冲锋枪 | 移动射击强、射速高 | 近距离叠加状态 |
| 霰弹枪 | 击退、破甲 | 守缺口、处理巨躯者 |
| 狙击枪 | 穿透、弱点伤害 | 击杀特殊感染者 |
| 轻机枪 | 持续压制、换弹慢 | 大规模尸潮 |
| 榴弹武器 | 范围爆炸、射速低 | 聚集敌人和装甲目标 |
| 火焰武器 | 持续伤害、区域封锁 | 再生与数量型敌人 |
| 电弧武器 | 连锁、控制 | 潮湿环境和机械寄生体 |
| 生化武器 | 消耗污染槽 | 高风险异化构筑 |

### 6.3 无限弹药的约束

所有普通枪械子弹无限，但通过以下参数保持武器差异：

- 弹匣大小
- 换弹时间
- 射速
- 散布与后坐力
- 有效射程
- 穿透和击退
- 过热与散热
- 移动射击精度

切到备用武器时，特定装备可提供后台换弹或散热，鼓励双武器轮换。

### 6.4 角色状态

- 生命：归零后倒地。
- 护盾：先于生命承伤，可通过装备或技能恢复。
- 伤势：跨昼夜的轻度负面状态，需要医疗处理。
- 污染：探索污染区和使用生化能力时增长；高污染强化异化能力，同时降低治疗或触发异常。
- 体力：只服务翻滚和少数重型动作，不与移动绑定。

## 7. 完整装备系统

### 7.1 装备槽位

- 两个主武器槽
- 头盔
- 护甲
- 手套
- 战靴
- 战术装置
- 进化器官

### 7.2 品质

普通、精良、稀有、史诗、传说、异变。

品质决定可出现的词条数量和机制上限，不直接保证所有高品质装备都适合当前构筑。

### 7.3 装备构成

1. **基础模板**：决定手感、基础属性和动画表现。
2. **固定特性**：例如霰弹枪击退、狙击枪穿透。
3. **随机词条**：按装备类型从受限词条池生成。
4. **进化特性**：史诗及以上装备通过使用行为解锁。

### 7.4 词条分组

- 输出：伤害、暴击、弱点、射速、穿透。
- 操控：换弹、散布、射程、移动射击精度。
- 元素：燃烧、感电、腐蚀、冻结。
- 生存：护盾、击杀治疗、翻滚减伤、受击触发。
- 联动：炮塔增伤、维修触发、方舟附近强化、对 BOSS 专精。

同类增伤词条采用收益递减，避免所有构筑只堆攻击力。

### 7.5 战斗记忆进化

史诗及以上装备记录玩家的使用方式，并在满足条件时提供二选一进化：

- 频繁近距离使用步枪：突击型，提高近战压制与移动射击。
- 频繁攻击弱点：猎手型，获得标记和弱点连锁。
- 经常保护方舟：守望型，靠近方舟时强化并联动炮塔。
- 经常触发元素异常：异化型，强化元素传播但提高污染。

进化路线可提前预览。玩家可消耗稀有资源重置一次，防止误选造成永久损失。

### 7.6 标签共鸣

不设置传统六件套，使用 2–3 件即可生效的标签共鸣：

- 三件“雷暴”：感电跳跃额外目标。
- 两件“守望”＋两件“机械”：玩家射击为炮塔标记目标。
- 三件“异化”：污染越高伤害越强，治疗效率下降。
- 两件“猎荒”：开箱速度与撤离移动提高。
- 三件“重装”：受击积累反击能量，但翻滚冷却延长。

标签允许混搭，使角色、装备和方舟形成同一流派。

### 7.7 制造、强化与拆解

- 制造：蓝图＋材料生成指定基础装备。
- 强化：提高基础等级，不增加额外词条。
- 改装：替换一个普通词条，重复改装成本递增。
- 拆解：返还材料，并提取标签或进化样本。
- 等级同步：消耗材料把低等级高品质装备同步至当前阶段。

制造负责可控进度，野外掉落负责惊喜。重要武器模板和蓝图都有明确获取来源。

## 8. 资源与经济

### 8.1 资源分类

| 资源 | 主要来源 | 主要用途 |
|---|---|---|
| 金币 | 普通丧尸、结算、交易 | 常规升级、维修、商店 |
| 废料 | 地图广泛搜刮 | 基础建造、强化、维修 |
| 机械零件 | 工厂、机械敌人 | 武器、炮塔、履带模块 |
| 电子元件 | 警局、实验区 | 雷达、电网、自动化 |
| 医疗物资 | 医院、幸存者事件 | 治疗、复苏、生化研究 |
| 变异组织 | 精英怪、污染区 | 角色、装备、方舟进化 |
| BOSS核心 | 章节 BOSS | 解锁关键科技和迁徙能力 |

新区域可加入高级合金、低温晶体等区域材料。旧材料始终可用于合成、维修和交易，不会完全失去价值。

### 8.2 掉落分工

- 普通丧尸：金币、少量废料。
- 特殊感染者：对应机制材料和装备概率。
- 精英怪：稳定掉落变异组织与较高品质装备。
- 宝箱：装备、蓝图和地点主题材料。
- 任务事件：可预期的指定奖励。
- BOSS：唯一核心、传说装备和下一章关键科技。

### 8.3 主要消耗

- 方舟维修与模块升级。
- 装备制造、强化和有限改装。
- 战前消耗品与紧急撤离。
- 幸存者治疗、训练和任务派遣。
- 高噪音诱敌模式的风险准备。
- 区域材料转换和旧材料再利用。

普通弹药不作为消耗项。经济重点是成长选择和损伤恢复，而不是购买射击资格。

### 8.4 经济控制原则

- 主线必需物品提供保底来源。
- 随机掉落只能加速或改变构筑，不能永久阻塞进度。
- 维修成本不能同时吞噬玩家的全部制造预算。
- 首章允许试错；从第二章开始逐步强化资源取舍。
- 重复刷低级区域的收益随角色阶段衰减，但蓝图和剧情收集不受影响。

## 9. 角色成长与科技树

### 9.1 角色升级

角色通过击杀、探索、事件和夜间防守获得经验。升级提供小幅基础属性与天赋点；特定等级解锁主动技能槽、进化器官槽或新功能。

### 9.2 天赋路线

#### 猎荒者

- 移动和撤离能力
- 搜刮效率
- 宝箱与隐藏点识别
- 背包与负重
- 污染抵抗

#### 枪械师

- 换弹和武器切换
- 弱点与暴击
- 元素状态
- 移动射击
- 双武器联动

#### 守望者

- 维修效率
- 炮塔联动
- 方舟附近增益
- 防线支援
- 应急供电

天赋允许混点，不锁死职业。后期节点改变玩法，前期节点以稳定易懂的增益为主。

### 9.3 方舟科技树

- 工坊科技：制造、改装和高级配件。
- 防御科技：炮塔、装甲、电网和维修无人机。
- 探索科技：雷达、情报、背包和撤离设备。
- 生化科技：变异组织、污染控制和活体模块。
- 能源科技：发电、储能、过载和供电优化。

关键科技需要 BOSS 核心，普通科技消耗金币和材料。玩家无法在单章内点满全部分支。

## 10. 怪物生态与人工智能

### 10.1 基础怪物职能

| 怪物 | 职能 | 主要威胁 |
|---|---|---|
| 行尸 | 数量型 | 消耗防线 |
| 奔袭者 | 高速追击 | 绕过火力、追击玩家 |
| 巨躯者 | 重装攻城 | 破坏路障和装甲 |
| 喷吐者 | 远程压制 | 腐蚀炮塔和地面 |
| 尖啸者 | 支援召唤 | 强化尸群并呼叫增援 |
| 攀爬者 | 绕后 | 从上层或后方进入 |
| 掘地者 | 潜行攻城 | 攻击内部设施和电缆 |
| 寄生体 | 机械干扰 | 使模块停机或反向攻击 |
| 自爆体 | 范围破坏 | 对密集防线造成爆炸 |

### 10.2 行为层级

普通怪物使用有限状态机：

```text
游荡 → 感知 → 追击 → 攻击/攻城 → 重新寻路
                      ↘ 受控/硬直 ↗
```

BOSS和复杂特殊怪采用分阶段行为树。决策、移动和攻击分离，路径只在目标变化或定时条件满足时重算，避免每帧寻路。

### 10.3 昼夜差异

- 白天敌人守护资源点、响应声音或在巢穴附近活动。
- 夜晚敌人按职能选择玩家、装甲、炮塔、电力或核心作为目标。
- 白天清除特定敌人和巢穴可以削弱夜晚对应威胁。

## 11. 尸潮导演与适应性变异

### 11.1 威胁预算

每晚拥有一个威胁预算，由以下因素确定：

- 当前章节和天数
- 方舟噪音等级
- 玩家上一晚表现
- 未清除的尸巢与特殊感染者
- 天气、事件和区域特性

预算用于组合怪物和波次，不直接随玩家战力无限增加敌人生命。玩家变强后主要面对更复杂的敌人组合。

### 11.2 标准夜晚结构

1. 预警期：显示主要方向和异常信号。
2. 试探波：少量敌人展示本晚机制。
3. 主攻波：多职能敌人协同。
4. 喘息期：允许维修、换装备和重新供电。
5. 高潮波：精英或特殊事件出现。
6. 清剿期：处理残敌并结算。

### 11.3 适应性变异

尸群记录玩家近期最依赖的战术，并在后续夜晚出现可预警、可反制的变化：

- 长期依赖火焰：出现耐热表皮，但电击抗性下降。
- 大量使用炮塔：寄生体和掘地者比例提高。
- 依靠高装甲硬守：巨躯冲撞者和腐蚀单位增加。
- 频繁低噪防守：出现侦察型尖啸者。
- 依赖高速移动：出现减速孢子区。

适应不会在当晚突然生效。雷达提前一天提示变异趋势，玩家可更换构筑、清理对应巢穴或研究克制科技。

### 11.4 精英词缀

- 装甲：正面减伤，背部弱点暴露。
- 狂热：附近敌人死亡后加速，可被控制打断。
- 电磁：周期关闭炮塔，蓄力器官可被击破。
- 分裂：死亡生成幼体，惧怕范围伤害。
- 再生：脱战回血，燃烧阻止恢复。
- 共生：与另一精英共享生命，需要调整击杀顺序。

普通精英最多一个词缀，高阶精英最多两个。每个强化点必须配备清晰表现和可利用弱点。

## 12. BOSS系统

### 12.1 设计原则

- 同时检验角色操作和方舟配置。
- 至少三个行为阶段。
- 第一阶段教授机制，第二阶段改变攻击路线，第三阶段压迫方舟核心。
- 白天探索应提供削弱 BOSS、获得预警或改变场地的任务。
- 失败后玩家能够明确判断问题出在装备、布局还是机制处理。

### 12.2 章节 BOSS

| BOSS | 核心机制 | 探索削弱方式 |
|---|---|---|
| 屠夫母体 | 召唤尸群、冲撞路障 | 设置废车障碍，诱导撞击暴露弱点 |
| 酸雨巨囊 | 腐蚀云、压制炮塔 | 修复净化器，降低酸雨覆盖 |
| 地铁吞噬者 | 地下突袭不同模块 | 获取震动探测器，提前显示位置 |
| 群脑信标 | 控制寄生体和远程尸群 | 摧毁信号巢穴，减少控制节点 |
| 原初进化体 | 根据玩家常用构筑切换适应形态 | 完成研究任务，揭示并锁定一个弱点 |

## 13. 章节与内容结构

完整主线规划五个区域、约 41 个昼夜。

| 章节 | 天数 | 区域规则 | 主要产出 | 关键解锁 |
|---|---:|---|---|---|
| 灰港废城 | 7 | 教学区，街道与基础室内探索 | 基础枪械、废料、医疗资源 | 方舟履带底盘 |
| 腐雨工业区 | 7 | 周期酸雨腐蚀护甲 | 合金、电子元件、元素装备 | 净化和元素防御 |
| 沉没地铁城 | 8 | 积水、地下路线、导电环境 | 精密机械、震动科技 | 地下探测与自动维修 |
| 群脑实验带 | 9 | 高污染、幻觉、机械寄生 | 生化器官、异变装备 | 完整活体模块进化 |
| 零号隔离区 | 10 | 多环境叠加、适应性尸潮 | 终极材料与方舟核心 | 结局与远征模式 |

## 14. 任务、事件与幸存者

### 14.1 任务类型

- 主线任务：修复迁徙路线、调查病毒、寻找方舟核心。
- 地点任务：清理医院、恢复变电站、打开军械库。
- 幸存者任务：救援、护送、寻找亲属、处理感染。
- 悬赏任务：猎杀精英、清除尸巢、回收指定物资。
- 动态事件：空投争夺、求救信号、游商、骗局、建筑坍塌。
- 夜间挑战：限制防御类型、保护设施、主动提高噪音。

任务奖励在接取前明确展示，允许玩家根据当前发展路线选择。

### 14.2 幸存者岗位

- 工程师：维修、制造、炮塔效率。
- 医生：治疗伤势、控制污染。
- 侦察员：揭示地图、宝箱和尸潮情报。
- 枪械师：改装武器、识别掉落。
- 生物学家：研究变异组织和进化路线。
- 守卫：夜间驻守指定模块。

每名幸存者拥有一个职业能力、一个个性特质、一条个人任务线和一个缺陷。幸存者不作为需要玩家逐个操作的战斗单位。

### 14.3 人员与士气

- 同一设施增加人数会出现收益递减。
- 受伤、污染或连续值夜会降低效率。
- 食物作为每日结算资源，影响士气和恢复，不显示实时饥饿条。
- 士气高提供轻度全局增益；士气低触发可处理的矛盾事件，不直接随机叛变。

## 15. 叙事设定与结局

病毒是一种能够记录威胁并快速适应的群体生物网络。移动方舟早期使用的实验能源与病毒同源，因此既能吸收变异核心进化，也会逐渐被群脑感知。

主线目标不是简单寻找解药，而是决定人类如何处理这种进化能力：

- **净化**：关闭生化核心，回归纯机械科技。
- **共生**：保留可控进化，承担长期污染风险。
- **支配**：利用方舟控制局部尸群，获得强大力量并改变幸存者关系。

结局由研究路线、幸存者任务和终章选择决定，不使用无法理解的隐藏分数。

## 16. UI、信息与移动端体验

### 16.1 白天探索 HUD

- 左上：生命、护盾、伤势与污染。
- 顶部中央：白昼进度和日落警戒。
- 右上：小地图、方舟方向、当前目标。
- 左下：移动摇杆。
- 右下：翻滚、技能、换枪、互动。
- 屏幕边缘：高威胁敌人、撤离方向和特殊事件指示。

### 16.2 夜间防守 HUD

- 顶部：方舟核心耐久、波次进度、剩余威胁。
- 左侧：关键模块耐久和供电警报。
- 右侧：应急供电、维修和主动设施按钮。
- 敌人头顶只显示必要状态；普通小怪不常驻显示血条。

### 16.3 方舟整备界面

- 总览页：核心等级、电力、噪音、装甲和次夜情报。
- 布局页：拖放模块、查看射界与供电线路。
- 工坊页：制造、强化、改装和拆解。
- 研究页：科技树和生化进化。
- 成员页：岗位、伤势、士气与个人任务。
- 仓库页：装备筛选、标签共鸣和方案保存。

### 16.4 操作与可访问性

- 支持按钮大小和位置调整。
- 自动射击可切换为“有目标时射击”或“持续射击”。
- 提供震屏强度、伤害数字密度、色弱标识和闪光强度选项。
- 关键警报同时使用颜色、形状、图标和声音，不只依赖单一颜色。
- 低端设备允许降低尸群显示数量，用等价集群单位保持战斗数值。

## 17. 美术与音频方向

### 17.1 美术

- 2D 横版，写实比例与适度夸张轮廓结合。
- 场景以低饱和灰蓝和锈色为主，交互资源使用更高明度。
- 方舟采用工业机械骨架，随进化逐步出现生物组织与发光脉络。
- 特殊感染者通过轮廓、攻击器官和警示色区分职能。
- 大规模尸潮优先保证轮廓和攻击预警清楚，不追求过度细碎的单体细节。

### 17.2 音频

- 白天以环境声、远处尸吼和低密度音乐营造探索压力。
- 黄昏通过警报、广播和发电机启动形成阶段切换。
- 夜间音乐按尸潮预算和波次动态增加层次。
- 特殊感染者拥有独立预警音，先听见再进入视野。
- 方舟模块使用不同机械音色，让玩家能凭声音识别停机、过载和受损。

## 18. 数值与难度基线

### 18.1 伤害关系

正式数值表实施时遵循以下关系：

```text
最终伤害 = 基础伤害 × 技能倍率 × 增伤乘区 × 暴击/弱点倍率 × 防御修正
```

- 同类加法词条进入同一增伤池。
- 暴击、弱点、元素易伤和方舟联动分别设置上限或收益递减。
- 普通敌人不会仅靠血量增长承担全部难度。

### 18.2 推荐击杀时间

| 目标 | 同阶段合理构筑 |
|---|---:|
| 普通行尸 | 0.5–1.5 秒 |
| 奔袭者/喷吐者 | 2–4 秒 |
| 巨躯者 | 6–10 秒 |
| 普通精英 | 15–25 秒 |
| BOSS单阶段 | 60–120 秒 |

### 18.3 难度增长

- 每日基础威胁稳定上升，但设置喘息日和资源日。
- 新怪物先在白天安全环境中出现，再进入夜间混合波次。
- 同一夜同时引入的新机制不超过两个。
- BOSS夜前至少提供一次明确的克制信息和一次准备机会。

### 18.4 资源节奏

- 普通探索成功应足以支付基础维修并完成一次有意义的小升级。
- 深入高风险地点应允许玩家提前完成一项关键升级。
- 一次失败不应让玩家连续多日只能偿还维修债务。
- 主线蓝图和章节核心均提供保底，不因随机数永久缺失。

## 19. 新手引导

第一章前七天承担完整教学：

| 天数 | 教学重点 |
|---:|---|
| 第1天 | 移动、自动射击、搜刮、返程 |
| 第1夜 | 炮塔、维修、基础尸潮 |
| 第2天 | 宝箱风险、背包、伤势 |
| 第2夜 | 供电切换与特殊感染者 |
| 第3天 | 工坊制造、装备词条和换枪 |
| 第3夜 | 多方向防守和喘息维修 |
| 第4–5天 | 幸存者、尸巢、动态地图 |
| 第5夜 | 首次精英夜袭和敌人弱点 |
| 第6天 | BOSS削弱任务、方舟进化预览 |
| 第7夜 | 屠夫母体与章节迁徙 |

教学优先通过安全情境和任务目标完成，避免连续弹窗。玩家首次独立完成操作后再解锁对应复杂界面。

## 20. 主线后的长期玩法

- 远征模式：随机区域规则和路线，挑战连续章节。
- 高危区：固定词缀关卡，产出外观和横向构筑奖励。
- BOSS再战：加入额外机制和评分目标。
- 方舟档案：收集敌人、地点、武器、人物和结局记录。
- 章节重访：保留全部成长，挑战高威胁旧地图。

长期玩法主要提供新构筑、外观和挑战目标，不依赖无限抬高装备等级破坏主线平衡。

## 21. 技术模块边界

结合当前 Cocos Creator 3.8.8 + Oops Framework 项目骨架，建议保持事件驱动和数据配置分离：

| 模块 | 职责 |
|---|---|
| battle | 战斗流程、昼夜阶段、伤害与波次调度 |
| role | 角色属性、状态、移动、技能与装备效果 |
| world | 章节地图、地点、动态区域状态、事件与撤离 |
| bag | 物品、堆叠、装备槽、仓库和掉落接收 |
| evolve | 角色、装备、方舟的进化规则与标签共鸣 |
| shelter | 方舟模块、布局、耐久、电力、噪音和维修 |
| monster | 怪物定义、状态机、精英词缀与 BOSS行为 |
| survivor | 幸存者、岗位、士气、伤势和个人任务 |
| economy | 资源、制造、强化、改装、拆解与商店 |
| save | 版本化存档、章节状态、动态地图与方案保存 |
| hall | 主界面、章节选择、继续游戏与档案入口 |

新增模块通过 `GameEvent` 交换结果，避免 UI、战斗实体和持久化状态互相直接持有。静态定义与运行时状态分离，所有物品、模块、怪物和任务使用稳定 ID。

## 22. 存档范围

存档至少包含：

- 当前章节、天数和昼夜阶段。
- 角色等级、天赋、状态和技能。
- 装备实例、词条、强化、进化路线与使用记忆。
- 背包、仓库、货币与材料。
- 方舟模块、布局、耐久、供电方案和进化。
- 区域捷径、尸巢、天气、已完成事件和 BOSS削弱状态。
- 幸存者、岗位、士气、任务和伤势。
- 图鉴、剧情选择、结局条件和设置项。

存档使用版本号和迁移规则。每日结算和关键稀有物品获得时执行增量保存，写入失败时保留上一份有效快照。

## 23. 开发范围建议

### 23.1 第一可玩原型

目标是验证“探索—整备—防守”是否成立：

- 一个白天街区。
- 一个方舟防守场景。
- 一把步枪、一把霰弹枪。
- 行尸、奔袭者、巨躯者三类敌人。
- 金币、废料、机械零件三种资源。
- 机枪塔、装甲板、发电机、工坊四类模块。
- 一次完整的白天返程、黄昏升级和夜间尸潮。

### 23.2 首章纵向切片

目标是验证完整商业品质的一章：

- 灰港废城七天流程。
- 五类探索地点与动态事件。
- 六类基础敌人、两类精英和屠夫母体。
- 六种武器模板、完整装备槽和基础词条。
- 方舟两级外观、布局、电力、噪音和基础进化。
- 一名可招募幸存者及其岗位和任务。
- 完整存档、设置、失败重试和章节迁徙演出。

### 23.3 完整版本

- 五章主线和三个结局。
- 完整武器、装备、怪物、BOSS、幸存者和方舟成长。
- 远征、高危区、BOSS再战和章节重访。

开发顺序必须先完成原型验证，再制作首章纵向切片，最后批量扩展内容；不能同时铺开五章资产生产。

## 24. 验收指标

### 24.1 核心体验

- 玩家能在 3 分钟内理解白天必须返程、夜晚必须保护方舟。
- 首章结束前，玩家至少做出三次有意义的路线或升级取舍。
- 自动射击不妨碍玩家主动选择高威胁目标。
- 方舟受损原因清晰，玩家知道如何通过布局或操作改进。
- 装备与方舟构筑至少形成三种可辨识玩法。

### 24.2 可读性与性能

- 大规模尸潮中，特殊感染者预警和角色位置始终可辨。
- 低端目标设备使用降级方案后仍保持稳定操作响应。
- 同屏单位数量、粒子、伤害数字和物理查询均设置预算。
- 存档在每日结算、失败重试和版本迁移后保持一致。

### 24.3 平衡

- 普通探索成功可以覆盖基础维修并产生正向成长。
- 单次失败不会让玩家进入不可恢复的资源负循环。
- 任何适应性变异都提前预警并至少存在两种反制方式。
- 主线必需蓝图、BOSS核心和剧情物品均有保底来源。

## 25. 主要风险与控制

| 风险 | 后果 | 控制方式 |
|---|---|---|
| 探索与防守像两个独立游戏 | 循环割裂 | 让尸巢、情报、天气、资源和 BOSS削弱双向影响 |
| 系统数量过多 | 新手负担大 | 第一章逐日解锁，原型只做最小闭环 |
| 自动射击缺乏操作感 | 战斗被动 | 目标标记、走位、换枪、翻滚、技能和维修提供主动决策 |
| 方舟布局过于复杂 | 移动端难操作 | 使用槽位、方案保存、射界预览和一键供电策略 |
| 适应性尸潮像作弊 | 玩家挫败 | 提前预警、明确弱点、限制适应频率和强度 |
| 装备随机度过高 | 难以形成构筑 | 定向制造、词条限制、保底蓝图和有限改装 |
| 全部成长继承导致滚雪球 | 后章失去压力 | 新资源层级、供电上限、环境规则和行为机制升级 |
| 同屏尸潮性能不足 | 掉帧和输入延迟 | 对象池、AI分级更新、集群单位、特效和数字预算 |
| 内容规模失控 | 无法完成 | 先原型、再首章纵向切片，验证后才扩展其余章节 |

## 26. 最终设计结论

本项目的核心身份不是普通横版射击，也不是传统静态塔防，而是：

> **玩家白天冒险养活方舟，方舟夜晚保护玩家；双方共同吸收末日生态的力量，并在不断升级的威胁中持续进化。**

后续所有功能和内容都应服务于这条关系。若一个新系统既不强化探索决策，也不强化方舟建设、战斗协同或进化构筑，则不应进入首发范围。
